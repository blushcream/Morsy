# Morsy

A simple yet beautiful Morse code translator.

Morsy converts text to Morse code and Morse code back to text. It also supports audio playback of the Morse code.

## Screenshot

![Morsy main window](screenshots/home.png)

## Features

- Text to Morse conversion
- Morse to text conversion
- Morse audio playback

## Built with

- Rust
- GTK4
- Libadwaita
